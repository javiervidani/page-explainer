# Tottom lessons: saved settings

Settings that worked for the NotebookLM lesson for Tottom (approved 2026-11-06). Use them for the next lessons for him.

## Who and what
- **Learner:** Tottom (WSC 2026 study; English).
- **Lesson id:** `study-smarter-with-notebooklm-for-tottom` (8 slides, built with voice).
- **Source of the screens:** the real study notebook in NotebookLM, captured with the team extension (PageLens auto mode). Private content: the lesson link stays behind the access token.

## Lesson settings
- **Language:** `en`
- **Voice:** `alba` (English). An English build is slow: about 4 minutes for 8 to 14 slides; do not start the same build twice.
- **Format:** `landscape`
- **Layout:** `snapshot` for every screenshot slide, with a `source` line under the picture (for example "NotebookLM – the Studio panel").
- **Pictures:** real screenshots only (`slides_add_from_drafts` with PageLens capture links). No generated pictures.
- **Narration:** plain English, short sentences, no niqqud. Address him by name on the first slide.

## Slide pattern (8 slides)
1. Meet the tool (whole screen).
2. What makes it special.
3. Step 1: add sources (Sources panel, crop).
4. Step 2: ask questions (question box).
5. Step 3: the Studio (panel with the tiles, crop).
6. Practice with flashcards (tile, element crop).
7. Test yourself with a quiz (tile, element crop).
8. Smart tips and a mission (whole screen).

## Capture settings that worked
- Auto mode with the tick, the notebook tab in front, a clean screen (no personal chats).
- `remote_capture` with `scope: panel` and `crop: true` for panels, `scope: element` and `crop: true` for single tiles.
- Press "Expand sources panel" first when the Sources panel is collapsed.
- A code lasts about 30 minutes and 60 commands.
