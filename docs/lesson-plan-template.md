# תבנית: מערך שיעור (קובץ MD) להזנה ל-LLM ול-Talkdeck

קובץ אחד לכל שיעור, או קובץ גדול עם כמה שיעורים. הכלי `lesson_import_script` של Talkdeck קורא אותו ויוצר את השיעור. הכלי הוא קוד רגיל (בלי מודל שפה), והוא יוצר שקפים בלבד: בלי קול, בלי תמונות ובלי תשלום. הקול נבנה אחר כך עם `lesson_build`.

העתיקו את החלק "הוראות ל-LLM" כמו שהוא אל ה-LLM שכותב את השיעורים.

---

## הוראות ל-LLM

כתוב כל שיעור בפורמט הבלוקים שלמטה, ורק בו.

1. **מבנה:** כותרת שיעור ברמה `#`, ראש שיעור בשורות `תווית: ערך`, ואחריו שקפים ברמה `##`.
2. **תוויות:** שורה אחת לכל תווית, בעברית או באנגלית. אסור להשתמש בתו `|`.
3. **מזהה:** `מזהה` באותיות קטנות באנגלית, ספרות ומקפים בלבד (למשל `1-2-hallucinations`), ייחודי לכל שיעור.
4. **כותרת:** עד 5 מילים.
5. **על המסך:** שורה אחת עד כ-40 אותיות, או רשימה (ראו למטה). בלי ספרות בתוך הרשימה.
6. **הקראה:** טקסט מנוקד מלא, כפי שצריך להישמע. בלי ספרות כרשימה (`1. 2. 3.`): כותבים "אחד, שניים, שלושה". מספרים בתוך משפט (`2 דקות`) מותרים.
7. **מספר השלבים:** מספר הפריטים על המסך שווה למספר הפריטים שמוקראים.
8. **פריסות:** רק מהרשימה: `full`, `snapshot`, `title-bullets`, `title-body`, `split`, `side-title`, `steps`, `cover`. אין להמציא שמות חדשים.
9. **תמונה:** בכל שקף שורה `תמונה:` עם `generated` או `screenshot`.
   - `generated`: חובה `פרומפט:` באנגלית. בסוף הפרומפט כתוב "no text in the picture".
   - `screenshot`: חובה `מקור:`. אם מדגישים כפתור, הוסף `כפתורים:` בשמות כפי שהם מופיעים בכפתור (באנגלית).
10. **אין שדות אחרים.** שדה לא מוכר נזרק או נשמר רק כהערה.

### חוקי בחירת פריסה

| תוכן השקף | פריסה |
|---|---|
| איור על כל המסך עם כותרת ושורה קצרה | `full` |
| צילום מסך שלם | `snapshot` |
| רשימת נקודות | `title-bullets` |
| שלבים ממוספרים | `steps` |
| תמונה וטקסט במידה שווה | `split` |
| כותרת גדולה במרכז (פתיחה/סיום) | `cover` |
| טקסט ארוך בחצי מסך | `title-body` |
| כותרת בצד ותוכן לידה | `side-title` |

## מילון שדות

| תווית (עברית / אנגלית) | משמעות | נשמר ב-Talkdeck |
|---|---|---|
| מזהה / id | מזהה השיעור | מזהה |
| שפה / language | `he` או `en` | שפה |
| קול / voice | `Osnat4` (עברית), `alba` (אנגלית) | קול |
| מטרה / goal | מטרת השיעור | `plan.goal` |
| כלים / tools | הכלי המודגם | `plan.tools` |
| זמן / time | חלק מהסרטון, `מ:ש-מ:ש` | `script.time` |
| כותרת / title | כותרת השקף | `title` |
| על המסך / screen | שורה, או רשימה (`-` נקודות, `1.` שלבים, שורה ראשונה שנגמרת ב-`:` כותרת משנה) | `screen`, `bullets`, `steps`, `subtitle` |
| הקראה / text | הטקסט המוקרא | `text` |
| רגש, הבעה, תנועות / emotion, expression, gestures | בימוי לאווטאר | `script.*` (לא משפיע על התצוגה) |
| ויזואליה / visual | תיאור לעורך | `script.visual` |
| תמונה / image_type | `generated` או `screenshot` | סוג התמונה |
| פרומפט / prompt | פרומפט באנגלית ל-`generated` | `image` |
| מקור / source | שורה מתחת לצילום מסך | `source` |
| כפתורים / buttons | שמות כפתורים שהתוסף מדגיש, מופרדים בפסיקים | `show.text` |
| פריסה / layout | אחת מ-8 פריסות הנגן | `layout` |
| סגנון / style | שם סגנון חופשי | `script.style_name` |

## קבצים גדולים

- קובץ גדול נשמר ב-`data/plan/` על ה-Pi, ומייבאים ממנו שיעור אחד: `lesson_import_script({ path, only: "<מזהה>", dryRun: true })`.
- `summary: true` מחזיר רק ספירות ואזהרות מקובצות.
- קודם תמיד `dryRun`, ורק אחר כך ייבוא אמיתי.
- ייבוא מחדש של שיעור קיים מחליף את השקפים ושומר תמונות. הקול נשמר לפי הטקסט.
- שמות פריסה ישנים (`full_screen_animation`, `ui_showcase`, `screen_demo`) עדיין נקראים ומתורגמים, אבל התבנית החדשה משתמשת בשמות הנגן ישירות.
